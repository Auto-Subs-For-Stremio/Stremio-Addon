# Subtitle tools

Open-source tools for subtitle files, by [Auto-Subs](https://auto-subs.com/) — our contribution back to the subtitle and translation community. Building a subtitle-translation service teaches you a lot about broken encodings, drifting timing and messy files; these tools put that knowledge in everyone's hands. Each tool lives in its own folder with its own README and runs on its own; none of them needs an Auto-Subs account.

| Tool | What it does | Open |
|---|---|---|
| [subtitle-toolbox](subtitle-toolbox/) | Fix garbled encoding (Hebrew, Arabic, Cyrillic, Greek…), shift or retime, convert SRT/VTT/ASS, fix right-to-left punctuation, check reading speed and overlaps. Runs in your browser, nothing uploaded. | [Launch](https://auto-subs-for-stremio.github.io/Stremio-Addon/subtitles-tools/subtitle-toolbox/) |

More tools will be added here. MIT licensed; issues and pull requests welcome.
